## CLI 4.x query gotchas:
##  - Filters must be SEPARATE shell args, not quoted into one string.
##      ✓ mod search . returns:ResponseEntity
##      ✗ mod search . 'returns:ResponseEntity'   (silently 0 in some states)
##  - `type:method` is a silent no-op; just use `returns:` / `throws:` directly.
##  - `type:symbol` is flaky — prefer `sym:Foo` for symbol search.
##  - `visibility:public` works alone and combines with `returns:` / `throws:`.

# Move into the working set so `mod search .` covers the whole portfolio.
cd multi-repo

# Open with familiar syntax — a literal scan, the kind of thing you'd reach for grep for.
mod search . '"RequestMapping"'

# Regex — finder-method names across every repo. Same shape as grep.
mod search . '/find\w+By\w+/'

# Symbol lookup — disambiguate the same name across multiple variants.
# `sym:` uses the trigram index over the LST; faster + LST-aware vs literal text.
mod search . sym:Owner

# Semantic filter: every method that returns ResponseEntity.
mod search . returns:ResponseEntity

# Semantic filter: every public method that throws IOException.
mod search . visibility:public throws:IOException

# Inheritance: classes that directly implement Repository.
mod search . implements:Repository

# Structural pattern with Comby — match a code shape, not a single token.
# Holes match balanced delimiters (parens, braces, strings).
mod search . 'struct:restTemplate.exchange(:[args])'

# --- Bridge to a recipe run -----------------------------------------------
## Cheap pass scopes the haystack. Precise pass runs only on matched repos.

# Cheap pass: literal `@RestController` anywhere in source.
# Catches imports, real usages, comments — wide net.
mod search . '"@RestController"'

# Precise pass: only on the repos the prior search matched.
# FindAnnotations resolves the FQN and reports actual annotation usage on
# declarations — no substring noise, no comment noise, no import noise.
# Watch for "Produced results for N repositories" — N should be < the
# working-set size.
mod run . --last-search --recipe=org.openrewrite.java.search.FindAnnotations -PannotationPattern='@org.springframework.web.bind.annotation.RestController'

## Heads-up beat for narration: sym:RestTemplate would catch the whole family —
## RestTemplateBuilder, OAuth2RestTemplate — because sym: is substring-on-FQN.
## That breadth is the motivation for the precise, type-resolving recipe pass
## above: FindAnnotations / FindTypes resolve the exact FQN.
